# UIC — Next.js agency website

The existing design migrated to Next.js App Router, React and strict TypeScript. Static sections use Server Components. Navigation, cinematic motion, project dialogs and the brief form have isolated client boundaries.

## Run

Use Node.js 20.9 or later:

If PowerShell blocks `npm.ps1`, use `npm.cmd` in place of `npm` in the commands below.

```powershell
npm install
npm run format
npm run dev
```

Open http://127.0.0.1:3000. Stop the previous preview if it occupies port 3000, or run `npm run dev -- --port 3001`.

## Validate and deploy

```powershell
npm run typecheck
npm run lint
npm run build
npm start
```

Commit the package-lock.json generated by the first successful install. Deploy to a Next.js-compatible Node host or Vercel. The previous custom preview server is no longer used.

## Structure

```
src/
  app/                 # Route composition, layout and metadata
  components/
    layout/            # Header and footer
    sections/          # Hero, studio, portfolio, services, NFC, process, contact
    forms/             # Project brief form and NFC interest link
    motion/            # Progressive reveal
  data/                # Typed portfolio content
  hooks/               # Scroll animation lifecycle
  lib/                 # Brief download utility
  styles/              # Responsive design and reduced-motion rules
```

Scroll writes scoped CSS variables through requestAnimationFrame instead of React renders. Listeners, observers and frames clean up on unmount. Content is visible without JavaScript. Native dialogs and disclosure controls retain keyboard behavior.

## Before publishing

- Replace labeled concepts with approved client work.
- Configure verified contact details and enquiry delivery. The form downloads a brief and sends nothing.
- Review copy and actual NFC offerings.
- The stylized SVG hero is preserved. Photorealistic motion requires a 3D/video asset.
- Google Fonts loads externally with system fallbacks; self-host approved fonts if required.
